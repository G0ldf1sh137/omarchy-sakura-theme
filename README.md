# Sakura

![preview](preview.png)

Pink/cherry-blossom Omarchy theme with sakura backgrounds.

An [Aether](https://github.com/tobi/aether)-generated theme for [Omarchy](https://omarchy.org).

## Install

```bash
omarchy-theme-install https://github.com/G0ldf1sh137/omarchy-sakura-theme.git
```

Or via Walker: `SUPER+ALT+SPACE` → Install → Theme → paste the URL above.
